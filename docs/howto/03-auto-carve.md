# Carving holes automatically

A forest region with trees still uncut: the Carve holes tool rings every obstacle the collision mesh shows and cuts the patches no mob was recorded on.

Zone: jugner_forest. Video: [03-auto-carve.webm](03-auto-carve.webm), cues: [03-auto-carve.vtt](03-auto-carve.vtt).

| At | Narration |
| --- | --- |
| 00:00 | This is Jugner Forest. Every tree or rock inside a region that is not cut out as a hole is ground where the server may try to spawn a mob. Cutting them one at a time is slow; the Carve holes tool finds them for you. |
| 00:19 | Select the region, here east three-ten. Some of its trees have holes, several do not. |
| 00:26 | The Spawns button shows it: green is where the server would put a mob, red a spot it throws away because it is off the walkable ground. |
| 00:37 | Open Carve holes. Amber outlines are obstacles found in the zone's collision mesh; violet dashed ones are patches no mob was ever recorded on. |
| 00:47 | Hover Ring all to preview everything it would cut. |
| 00:52 | Click it, and each obstacle becomes a hole. |
| 00:56 | Cut patches does the same for the empty ground. The clearance dial above it keeps each patch that far from where mobs walked. |
| 01:05 | A cut that would split the region in two is left alone, and says so. Anything left dashed is too big for Ring all, usually a cliff or a hillside: click it on the map to cut it on its own, or leave it. |
| 01:24 | Press Escape to leave the tool. The new holes are ordinary holes: drag, grow or delete them like any other. |
| 01:32 | Every cut is one step in History, so Control Z takes back the last one if it went too far. |
